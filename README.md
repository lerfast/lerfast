## 🚀 Proyecto actual: [Oshlix](https://www.oshlix.com) — IA para la Seguridad Laboral

Estoy construyendo **Oshlix**, una plataforma impulsada por IA que combina analítica en tiempo real y modelos predictivos
para ayudar a las organizaciones a prevenir incidentes, cumplir normativa y reducir costos en entornos de alto riesgo.

- **Enfoque:** inteligencia de seguridad, cumplimiento, prevención de incidentes  
- **Stack:** React (frontend), Ruby on Rails (API), PostgreSQL  
- **Por qué:** decisiones basadas en datos, no suposiciones
